# Bundled application fonts

Unmodified Noto Sans SC Regular and Bold, from the official Noto CJK project:

- https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/SC
- License: SIL Open Font License 1.1; see OFL.txt.

Downloaded 2026-10-25. Copyright/name metadata in the original font files is
retained. Do not describe these fonts as public-domain or copyright-free.

The application uses Regular for interface text and Bold for its brand title.
No proprietary OS font is copied into the package. On Switch, fonts and OFL.txt
are packaged under RomFS/fonts; native builds also stage them under romfs/fonts.
