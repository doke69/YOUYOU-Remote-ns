# 外设手柄前端与输入规则

候选 `0.3.75-r9ui`，在 R8 源码上修正工具栏提示重叠、远程布局命名及说明页与设计稿的差异。仅本地候选，不部署、不上传。先前 R6/R7/R8 文档与审查记录保留为历史证据；当前手柄逻辑以本文和使用手册的候选章节为准。

## 当前规则

- 保留既有深色、蓝色焦点、全屏设备页及右侧抽屉。外设手柄页按玩家选择，操作说明分本地菜单与远程游戏。Xbox/PS 与 Switch 共用圆润无突出握把的简图，PS 面键图形由几何笔画绘制。
- 本地菜单始终右侧面键确认、下侧面键返回：Switch A/B、Xbox B/A、PS ○/×；横握 Joy-Con 按位置操作。不受远程布局影响。
- 启动默认手柄直连；选择新模式后确认才生效。取消/返回不变。本次运行内重连保持已确认选择，重启应用恢复手柄。键鼠仅玩家 1。
- Minus 不再做本地检测或延迟短按，保留按住/松开输入。完整手柄为 Back；左横握 Joy-Con 为 Start，且不折叠成 Plus。左 Joy-Con 本地菜单由另一只手柄 Plus/Start/OPTIONS 或掌机触屏打开。右 Joy-Con 短 Plus 为 Start，长 Plus 为菜单。
- 删除自定义页面、绑定数据类型和输出覆盖；旧 `gamepad_bindings`、`input_mode` 被忽略且不再保存。其余合法偏好继续读取。
- Switch/Joy-Con 按位置/按字母预设继续共用；Xbox/PS 图示按标准位置输出，不套用 Switch 字母预设。已知 Joy-Con/掌机自动识别；普通完整 HID 手柄由用户按玩家位置选择图示，无法声称自动识别品牌。
- 单 Joy-Con 显示 SL/SR、原 L/ZL 或 R/ZR，说明对应 LB/RB、LT/RT；单摇杆且无独立十字键或第二摇杆。
- “远程按键布局”只改变电脑游戏收到的按键；抽屉同时列出按位置/按字母的例子和不变的本地规则。说明页恢复设计稿的两列卡片与图形比例、配色、圆角及按键间距；横握右 Joy-Con 显示 X/A/Y/B 实体字母。
- 工具栏不在快捷按钮所占的 y=110 提示区域绘制暂停说明，避免文字从“退出／键盘／声音”之间露出；其他有标题的抽屉保留该提示。

## 验证

手柄离线测试覆盖横握坐标、预设、Minus 连续输出且不产生 Plus、肩键/扳机、本地导航隔离及 Plus 长短按生命周期。当前 LiveFrontend 源码的隔离原生 SDL 软件渲染器检查首选项迁移、启动默认、确认/取消/返回、重连、图示及布局作用域和断开状态，并导出 1280×720 截图。它不会创建真实 Client、读用户凭据或连接电脑。

R9 新增工具栏两个按钮间隙的逐像素检查及多次返回测试；同一检查在未改动的 R8 前端上失败，在修正后通过，具体见 `C:/uu/releases/diagnostics/peripheral-ui-r9-20261108/r8-regression.log`。

构建及代码审查记录：`C:/uu/releases/diagnostics/peripheral-ui-r9-20261108/REVIEW.md`。尚需真机确认 Switch 渲染、外接适配器的 HID 物理位置、TV 模式菜单入口、两人游戏输入及震动归属；离线截图不等于真机验收。
