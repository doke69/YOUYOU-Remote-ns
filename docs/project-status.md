## 已实现

- 扫码／短信登录、会话恢复、设备刷新及最近成功连接电脑。
- H.264／H.265、Opus、NVDEC 硬件解码与原生 Deko3D 显示。
- 5／12／20／30 Mbps 上限快捷档（自定义入口暂时隐藏）、播放缓冲、垂直同步和网络信息。
- 协商后的 TWCC-01 反馈及经典 RBE／REMB 回退。0.4beta 构建脚本沿用 R67 参数，TWCC-02 广告关闭。
- 中继／通道未知请求最高 20 Mbps，直连恢复用户上限。
- 两路手柄与横握映射、两套键鼠方案、手机鼠标、平板多点触控、按玩家震动、文字输入和 Windows 操作。
- 安全页声音、锁屏及互斥屏幕保护模式，安全请求带有限发送重试；实际隐私状态通知、增强隐私能力声明和每轮自动光标捕获。
- L + ＋ 统一打开／收起串流菜单，首页长按 ＋ 退出；完整手柄、Xbox、PS 与单 Joy-Con 操作说明同步。
- 减少高频缓冲申请、状态复制和压缩帧复制，断开诊断后台写入。

## 仍需验证或尚未交付

- 整合后的双玩家／适配器／震动、声音恢复、休眠、重连及长期弱网兼容。
- 个别用户建连失败的剩余原因，TURN TCP／TLS 不同部署的互通。
- Windows 电脑键盘入口此前有无法弹出的反馈，触摸自动弹出还受电脑设置及应用支持影响。
- 隐私／息屏连续重连与自动光标恢复在报告场景已获用户复测确认；其他电脑版本和显示环境仍需验证。
- 原生 IPv6、原生 DS4／DualSense 输出、PS 触摸板及自动解锁。
- 50–100 Mbps 稳定串流及 Lite／标准机同等耗时没有保证。R67 仍有缺包恢复和关键帧等待停顿。

实际码率、设置请求和电脑确认分别展示。初传缺口不等于 Wi-Fi 永久丢包，解码耗时包含软件处理及等待。完整更新见[0.4beta 说明](releases/v0.4beta.md)。
