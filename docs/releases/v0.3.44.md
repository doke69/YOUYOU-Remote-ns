# YOUYOU Remote NS 0.3.44

本次以完整源码快照更新，不需要叠加旧功能PR。保留原作者、依赖许可证及致谢；只发布源码，不附NRO、ELF或NSP。本地基准成品不是已脱敏的公开发行包，见[分发说明](../distribution.md)。

## 更新

- 首次连接携带能力JSON及 `choose_resolution`，请求720p/1080p输出，避免2K首帧触发CPU显示回退；保留NVDEC/Deko3D硬件直出路径。
- 帧率、画质使用独立协议消息；专用消息被拒时使用兼容请求。画质/码率更新被拒后保持旧串流，不因此重连。
- 分辨率切换显式重连，适配当前测试主机行为。
- 区分 accepted（请求接受）、applied（同步确认应用）、rejected（请求拒绝）。可选解析 `CaptureSettingSync`，不会把ACK直接标为已生效。
- 保存 `forward_setting` 的显示与编码器能力信息，诊断区分目标设置、实际媒体尺寸、解码/显示及回退状态。
- 当“串流时电脑静音”和“结束后恢复声音”均开启时，断开前发送恢复声音命令，并等待180ms后关闭连接。

## 验证范围

交接真机记录确认720p路径 `media=1280x720`、`hw=1`、`fallback=0`、`cpu-transfers=0`，并确认断开后电脑声音恢复。本次发布核对源码清单和已有基准产物哈希；没有用重新构建或重复现场测试替代这些记录。

这不表示任意主机、1080p或网络环境都得到同等覆盖，也不表示电脑桌面独立分辨率的全部行为均已验收。协议请求、实际收到尺寸和主机桌面尺寸应分别核对。

## 已知限制

- 当前测试PC未发送 `CaptureSettingSync`，applied状态保持未知。
- 分辨率变化会重连；画质被拒时维持原设置与画面。
- actual-fps是短窗口统计，可能波动，不能单独作为性能结论；解码耗时包含提交/等待。
- 2K硬件帧直接导入、原生IPv6及部分功能仍未完成或未充分验证。
- 虚拟显示器、私密屏、完整文件/剪贴板功能、自动解锁不在本次交付范围。
- 不保证50–100Mbps稳定串流，也不保证Lite和标准机延迟完全一致。
