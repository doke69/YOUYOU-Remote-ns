# 0.3.72 源码快照

本版本为当前本地源码的脱敏快照，版本以 CMake 项目版本为准。包含登录与设备管理、视频接收和解码、原生显示、播放调度、画质与码率请求、触屏与控制等现有功能。

## 播放与诊断

- 播放路径按解码时间和播放延迟计算可呈现时间；选择逻辑优先输出到期帧，仅在超出迟到预算时丢弃过期帧。
- 保留解码、选帧、显示提交间隔和实际码率的数值诊断，便于区分各阶段。
- 码率档位是发送给主机的目标或上限，不代表实际码率恒定。

## 验证边界

已有真机日志显示 720p 视频可硬解，但部分场景仍有显示提交间隔波动，目标码率与实际码率也可能不同。不能仅依据编译或平均帧率宣称卡顿已经解决。设备、网络、断连恢复、安全功能及所有设置的完整回归仍需验证。

本次仅更新源码和文档，不包含签名材料、配对数据、原始日志、APK 或 NRO/NSP 等构建产物。配置和认证材料的使用、构建及分发边界详见 [分发说明](../distribution.md)。
