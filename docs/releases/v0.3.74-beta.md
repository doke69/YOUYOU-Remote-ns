# 0.3.74 Beta

本测试版在 0.3.73 Beta 的基础上，整理屏幕保护相关页面。

## 更新内容

- 安全页增加“屏幕保护”入口，主页面保留锁屏和音频设置。
- 将“隐私保护”和“关闭显示屏”放到独立子页，避免安全页内容溢出。
- 两种电脑端模式互斥；页面区分已确认、等待和未确认状态。较长提示会按字体宽度换行。
- 保留 PrivacyScreenSetting 协议、优化了连接/配对、画质和媒体传输路径。

## 验证与限制

- 屏幕保护功能的上一版已由用户在设备上测试正常。
- “关闭显示屏”采用电脑端增强隐私模式，效果取决于电脑端与驱动支持；RPC 应答不保证所有显示器都已断电。
- 本测试版不代表整体串流、不同主机环境或长时间运行已完成回归。
- 公开 GitHub Release 提供 `UURemote-ns.nro` 与 `SHA256SUMS`。源码仓库不包含该二进制；合并后由维护者附上本地构建的 NRO。
