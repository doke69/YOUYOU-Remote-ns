# 0.3.9 更新与验证

日期：2026-10-25。本次同步当前完整源码，不是仅发布相对于v52的局部补丁。

## 累积变化

- 配置读取收敛至线程安全ConfigStore，默认配置版本2：720p60、H.265、20Mbps、vsync、8ms播放缓冲。保留受支持的已有自定义值。
- 原生菜单、登录恢复、安全/键盘/触屏与画质页面迭代；可用性及限制见用户手册。
- 用户选定新图标；Noto Sans SC字体及许可随源码提供。
- 0.3.7曾因文件式字库带来首页CPU3高占用和连接异常；0.3.8将字库一次读入内存，用户确认改善。当前保留该修复。
- 0.3.9按实际字形可见区域对齐文字，检查标签、按钮、菜单和触屏控件；仅在纹理缓存未命中时测量边界。
- 首页记住最后成功连接电脑的ID；重开/列表重排后恢复，失败连接不覆盖记录，离线状态不伪装在线。
- 常驻网络信息放在左下角，半透明黑底alpha115/255。
