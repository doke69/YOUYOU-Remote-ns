# YOUYOU远程 0.4beta

> 更新说明已检阅 · 2026-11-13 · 本次同步源码，Release 附件另行发布

本次整合 R67 性能优化、双手柄与外设功能，并补充连接、断开、屏幕保护及鼠标指针相关修复。与上个公开版本 0.3.74 Beta 相比，主要变化如下。

## 安装必读

**0.4beta 请按全新安装方式使用。** 正常退出旧程序，先把需要留存的 `switch/UURemote-ns/` 文件夹备份到电脑，再清空 SD 卡上该文件夹的全部内容。将本版 NRO 放入清空后的文件夹，首次启动重新登录并设置参数。请勿将旧的配置、会话、界面偏好或其他旧文件覆盖回新目录。

## 画质与连接

- 画质快捷档统一为省流最高 5 Mbps、清晰最高 12 Mbps、高清最高 20 Mbps、原画最高 30 Mbps，与自定义码率共用同一设置路径。它们会选择 Q6 自定义上限，实际输出随画面复杂度、网络和电脑编码器变化。
- 暂时隐藏自定义码率入口，前端只提供四个上限档位。后台继续使用同一套码率请求与反馈逻辑。
- 新安装默认使用 720p／60 FPS、H.265、12 Mbps 上限、垂直同步关闭和 0 ms 播放缓冲。本版全新安装后按默认配置开始，需重新登录并设置。
- 中继及尚未确定通道时自动请求最高 20 Mbps。用户设得更低时沿用较低值，局域网和公网直连恢复用户上限。后台保护不会覆盖保存的用户值。
- 整合 TV 客户端参考链路的 TWCC-01 反馈及经典 RBE／REMB 回退。构建配置沿用 R67，TWCC-02 广告关闭。只有共同协商与真实到包信息满足条件时才启用相应反馈。
- 补齐控制请求包装、压缩 SDP 和 Socket.IO 二进制附件处理，限制损坏或超大消息，增加连接阶段、队列和首帧诊断。部分 TURN 桥失败可进入既有恢复流程。
- 连接期间避免设备列表刷新阻塞信令处理。画质保存、信令 I/O 和选中通道查询按 R67 配置移出实时控制线程。
- 调整视频尺寸请求与确认流程，按实际帧尺寸判断结果，并保留有限重试及失败提示。

中继 20 Mbps 是客户端请求与反馈约束。电脑是否执行仍需结合主机状态和实际流量核对，尤其是旧配置使用主机原生质量档时。网络页中的实际接收码率可能含重传、包头及统计窗口差异。

## 屏幕保护与鼠标指针

- 修复断开后再次连接时，屏幕保护开关沿用历史选择、与电脑实际模式不同步的问题。现在优先显示电脑报告的状态；尚未收到确认时显示“未确认”，设置处理中显示“等待电脑”。
- 修复屏幕保护请求超时后，迟到的有效回包无法更新状态的问题，同时避免旧请求覆盖新请求。
- 补齐增强隐私能力声明，修复已保存“关闭显示屏”后，再次连接却回退到普通隐私保护的问题。该场景已获得用户复测确认；电脑自身不支持或执行失败时仍可能回退，并会显示实际结果。
- 每轮连接在首帧出现、设置通道就绪后，自动请求开启电脑端光标捕获，改善隐私／息屏重连后能操作却看不见指针的问题。自动恢复已获得用户复测确认。
- 保留“外设 → 鼠标设置 → 恢复鼠标指针”手动入口，供自动处理未生效时重试。
- 精简“安全 → 屏幕保护”页面，仅保留“隐私保护”“关闭显示屏”两个互斥开关；点击当前已开启项即可关闭，不再单列重复的“关闭屏幕保护”按钮。调整状态提示排版，避免较长提示被截断。

光标修复使用电脑端既有捕获请求，不额外绘制本地鼠标箭头。隐私保护与关闭显示屏的实际效果取决于被控电脑的 UU 版本、权限和显示环境。

## 性能与诊断

- 批量收包复用线程内序列化缓冲，减少高频申请与释放。保留 R64fix 的线程局部存储编译修正。
- 减少控制线程与界面反复复制完整状态，设备列表和网络信息布局在内容变化时更新。
- 合并 RTP 统计的重复检查和锁区，修正合法短 SR 的漏计，分别展示初传缺口和接收统计。
- HEVC 分片直接拼入最终压缩帧，减少临时扩容与复制。
- 完整压缩帧在容量与尾部补零条件满足时向 FFmpeg 移交所有权。条件不足时沿用复制路径，保留异步引用与释放规则。
- 整合 R67 已有恢复策略，减少无意义的定期关键帧请求，纯自定义上限切换可跳过额外的 ACK 关键帧请求。
- 默认启用精简统计，关闭重型逐包追踪。解码分析页会标明未采集的分段指标。


## 外设与操作

- 两名玩家分别维护连接、输入、释放和震动状态，增加系统手柄连接／顺序入口，适配完整手柄及左右 Joy-Con 横握。
- 启动默认手柄模式，Switch／Joy-Con 的远程按键布局默认按字母。切换键鼠或手柄模式需在“外设 → 手柄设备”中选择并确认。减号继续发送给远端，避免与游戏操作冲突。
- 重新整理 Switch、Xbox 360 和 PS4 DualShock 4 图示及说明，区分本地菜单与远程游戏按键。远程按键布局提供按位置／按字母预设，移除实验性自定义改绑。
- 本地菜单按右侧面键确认、下侧面键返回。两种串流模式统一用 L + ＋ 打开或收起菜单（Xbox：LB + Start；PS：L1 + OPTIONS），手柄模式单独按 ＋ 发送远端 Start。右 Joy-Con 使用 SL + ＋。左 Joy-Con 的菜单入口使用另一只手柄或掌机触屏。
- 增加手柄震动关闭／弱／中／强设置，菜单、失去焦点、断开及超时停止震动。
- 精简手柄设备页提示，修正工具栏透字、图示比例和说明卡片排版。
- 串流工具栏增加“电脑键盘”入口，发送 Windows 屏幕键盘快捷键。“外设 → Switch 文字输入”保留本地编辑与发送入口。此前电脑键盘测试有未弹出的反馈，这项兼容问题仍需排查。


## 稳定性修复

- 垂直同步由主循环根据已接受的设置统一应用，避免请求被拒绝后实际状态与界面不一致。显示后端应用失败时显示“未能应用”。
- 组合键仅释放本次新增按下的键，保留用户已经按住的修饰键，修复按住减号再触发 Win+D 时提前释放 Win 的问题。
- 安全设置遇到控制通道拥塞或发送异常时，在五秒期限内重试。新选择替换尚未提交的旧选择，已提交的操作移出队列，超时显示提示。
- 断开先释放远端输入，再停止接收器。接收器诊断改为后台落盘，避免慢 SD 写入拖住清理。上一份仍在写入时跳过后续快照，并记录 writer-busy。

- 修复自动缩放应答与实际画面到达顺序不一致时，正确尺寸画面已经出现却仍继续核对的问题，保留实际帧尺寸验证。
- 更准确识别当前选中的 TURN TCP／TLS 中继桥：选中桥失败时进入既有恢复流程，备用桥失败不会误判为当前连接失败。
- 调整 TCP／TLS 中继会话断开顺序，在关闭过程中短暂保留转发桥，为已排队的关闭消息留出发送机会；链路已经中断时仍无法保证送达。

## 验证与已知限制

- R67 独立候选已有本机回归、Switch 构建和一次真机使用反馈。整合版的本机测试、构建及差异核对记录见 [整合检阅记录](../reviews/v0.4beta-integration.md)。
- 后续连接修复、菜单组合键和屏幕保护改动已分别通过相关本机回归与 Switch 构建校验；这些检查不替代完整真机验收。
- 用户已复测确认连续重连后关闭显示屏不再回退、鼠标指针可自动恢复。最新页面精简已通过离线界面检查，仍需随最终整合包完成真机回归。
- 最终待发布整合包仍需统一验证连接／重连、画质切换、双手柄、声音恢复、安全设置和退出，不能把分阶段测试包的验证等同于所有环境均已通过。
- 个别用户停在连接建立阶段的问题仍需结合诊断定位，新增诊断及恢复逻辑未覆盖所有原因。
- Windows 屏幕键盘唤起仍有未弹出的反馈；当前光标修复已在报告场景有效，但未覆盖所有电脑版本和显示环境。不同 TURN 网络、双手柄及长时弱网仍需扩大测试。

本次更新为源码同步；公开测试包的独立 Release、下载附件和校验值另行提供。

本版安装将重建本地配置、登录会话和偏好，请按“安装必读”操作。源码继续遵循 GPL-3.0-or-later，第三方组件沿用各自许可证，新增 libnx 适配代码附 ISC 声明。
