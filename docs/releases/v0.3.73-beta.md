# 0.3.73 Beta

本版本为测试版源码快照，主要更新音频播放与自定义码率设置。

## 主要更新

- 保留省流、清晰、高清、原画四档主机预设；新增自定义最高码率 8、15、20、30、40、50 Mbps。自定义档向主机发送对应上限，并在协商支持时发送同值 REMB 反馈。上限和反馈不保证实际输出速率；固定高反馈在网络较差时可能造成拥塞。
- 自定义配置保存在配置文件中；从主机预设切换至自定义模式需要重连。已有旧配置按配置版本迁移。
- 音频包按 RTP 时间戳短暂缓冲，缺包时使用 Opus PLC 补偿；较大空隙可能触发重置。此机制不等于完整音画同步。
- 保留网络信息、实际接收码率、帧处理与播放统计，用于区分请求设置和实际表现。

## 验证与限制

已有掌机测试记录显示 720p、H.265 串流在部分场景可正常运行，实际码率随画面变化；主机没有在该记录中返回实际采用的码率。尚无同场景 REMB 开关对照，不能证明反馈提高了码率。音频断续、静音恢复、音画同步、弱网与长时间使用仍需专项测试。

本次发布仅包含源码和说明；不包含认证材料、配对信息、日志或 NRO/NSP 等成品。构建方式见 [构建说明](../build.md)。
