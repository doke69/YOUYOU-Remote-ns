# 0.3.73 Beta

面向 Nintendo Switch 的非官方远程客户端公开测试版。

## 更新内容

- 保留省流、清晰、高清、原画四档主机预设，自定义最高码率为 30、50、75、100 Mbps。自定义档请求上限，并在支持时发送固定 REMB；实际码率取决于电脑、画面和网络。高码率不保证流畅。
- 自定义画质与相关参数会保存；旧自定义上限不再仅凭数值转换为主机预设。
- 主动断开前尝试恢复电脑声音并等待控制通道；用户反馈一次恢复正常，异常断网或强制关闭不保证送达。
- 键鼠方案按 Switch 实体位置对应 Xbox：B/A 为回车/Esc，方案一 Y/X 为鼠标左/右键，方案二 Y/X 为空格/退格。本地菜单仍为 A 确认、B 返回。
- 更新 Switch 按键示意、操作提示与关于页面。

## 安装

从 Releases 下载 NRO，放入 SD 卡 `switch/UURemote-ns/`，使用完整应用模式启动。更新时保留现有配置和账号数据。

## 验证与限制

Switch 编译通过；此前配置、码率与输入的三项定向测试通过。已有真机使用反馈；最新关于页和按键映射需要进一步真机验证。音画同步、弱网和长时间运行仍需测试；固定 REMB 不是自适应带宽估计。原生 IPv6 尚未完成。

源码仓库不包含 APK、独立签名文件、用户配置、配对或日志。NRO 内嵌构建时提供的客户端通用请求签名材料，第三方材料的权利需分别确认。FULL 构建还使用本地提供的 UI 资源，公开源码单独不足以复现这份资源包；详见 [构建说明](../build.md)和[分发说明](../distribution.md)。
