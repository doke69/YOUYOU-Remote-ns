# v0.1.52 审核候选

## 主要新增

1. 多点触控采用二进制控制通道的 START/MOVE/END/CANCEL 与完整触点快照，最多10点；HID finger_id映射为稳定编号。菜单／失焦／断开会取消触控，移动包合并限速，生命周期另行处理。
2. 串流中长按−约650ms切换原生手柄与键鼠映射。短按在释放时发送Tab/Select；本地菜单仍A确认、B返回。Xbox按字母／按位置设置独立于菜单。
3. 常驻网络信息保留实际数值，详细页解释通道与统计。未知端到端时延保持未知。
4. 延续51的登录保存、抗锯齿圆角和手机式鼠标手势。
