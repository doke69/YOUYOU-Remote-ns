# v0.1.9 — 网络信息面板（类 UU 原版检测）

本版新增远程桌面内的网络/串流信息面板，用于查看丢包、延时、编解码方式等真实运行状态。

## 使用

远程桌面中按 **R3**（右摇杆按下；键盘为 **F3**）显示或隐藏，每 0.5 秒刷新。面板内容：

| 行 | 内容 |
| --- | --- |
| 网络 | 与电脑的 RTT（SCTP/DTLS 同一 UDP 路径测得的往返时延）、连接方式（局域网直连 / P2P 直连 / TURN 中继）、传输协议（UDP/TCP） |
| 视频 | RTP 丢包率、RFC 3550 抖动、码率（近 1 秒窗口） |
| 编码 | H.264 档次@级别（来自 SPS）、分辨率、解码帧率、对端编码器标识（来自 SEI：x264 软编 / NVENC、QSV、AMF、VideoToolbox 硬编） |
| 解码 | NVDEC 硬解或 FFmpeg 软件解码、单帧解码耗时、解码错误与丢帧计数 |
| 关键帧 | PLI 请求次数、最近一次「请求 → 收到 IDR」的恢复耗时 |
| 音频 | Opus 码率、丢包率 |

## 实现

- 新增 `source/stream_stats.cpp`：`uu::RtpTrackStats` 作为 `rtc::MediaHandler` 插入音视频 track 的 handler 链末端，
  直接统计原始 RTP 包（序列号缺口算丢包、RFC 3550 抖动、1 秒窗口码率）。
- `source/media.cpp`：解析 Annex-B 码流中的 SPS（档次/级别）、SEI user_data_unregistered（编码器标识）与 IDR；
  统计解码帧率、单帧解码耗时（EMA）、解码错误与丢帧；暴露 `MediaStats`。
- `source/client.cpp`：连接建立后以 0.5 秒周期汇总 `PeerConnection::rtt()`（SCTP srtt）、
  选中候选对（局域网/P2P/TURN）、音视频 RTP 统计与解码统计，缓存给 UI 线程读取；
  同时记录 PLI 请求次数与关键帧恢复耗时。
- `source/main.cpp`：R3/F3 切换面板，半透明黑底 + 等宽行排版；覆盖层顶部提示同步加入「R3 网络信息」。

> 延迟说明：面板中的 RTT 是网络往返时延（与 UU 显示的「延时」口径接近），不是端到端采集延迟；
> 「关键帧恢复」用于观察 Wi-Fi 丢包后的恢复速度。编码器标识依赖对端编码器写入 SEI，
> 未写入时显示「—」（例如部分 NVENC 配置）。
