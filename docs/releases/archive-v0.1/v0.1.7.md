# v0.1.7 — 系统 23.0.1 / 大气层 1.12.1 适配

本版基于 v0.1.6，为 **系统 23.0.1 + Atmosphère（AMS）1.12.1** 完成构建与运行适配，并同时适配 **初代 Switch 与 Switch Lite**。

## 变更

- 新增机型与系统识别：通过 `set:sys` 的 `setsysGetProductModel()` 区分 Switch / Switch V2 / Switch OLED / **Switch Lite**，
  读取固件版本并写入 `connection.log`（`console-<机型>-<模式>-fw<x.y.z>`），首页底部显示「机型 · 模式 · 系统版本」。
- 新增底座 / 掌机显示适配：TV 模式使用 1920×1080 窗口，掌机（含 Switch Lite）使用原生 1280×720；
  SDL2 驱动在插拔底座时自动切换，UI 与触控坐标仍按 1280×720 逻辑尺寸计算。
- TV 模式远程桌面覆盖层提示「触屏不可用」。
- 以 devkitA64 r30 / GCC 16.1.0 / libnx 4.12.0 重新交叉编译并打包；libnx 4.12.0 已包含 23.0.0 的 svc/spl 类型更新，
  且带有 21.0.0 之后的 TLS ABI 标记，23.0.1 + AMS 1.12.1 上 hbmenu 不会提示 ABI 不兼容。
- 新增 `docs/firmware-23.0.1-ams-1.12.1.md` 适配说明与真机自检清单。
- 打包拆分为 `-switch.zip` 与 `-switch-lite.zip`（NRO 完全相同，仅安装说明按机型区分）。

## 验证

- 交叉编译与 NRO 打包通过（Windows + devkitPro 锁定 SDK，devkitA64 r30 / GCC 16.1.0 / libnx 4.12.0）。
- NRO 检查：NRO0 头、ASET 资源段、RomFS 内 `signing.key`、NACP 标题 / 作者 / 版本 `0.1.7` 均正确；
  NRO SHA256 `8dda4e6451b4e2cf34072882b4518e9f719bc254c435383ec1b195e0fddf0ec2`。
- 本机原生测试 6/6 通过（protocol、auth、background_lifetime、rtc_diagnostics_privacy、signaling_fairness、
  switch_tls_nonblocking），`tests/switch_sctp_layout_test.py` ABI 检查通过。
- 真机验证仍需在 23.0.1 + AMS 1.12.1 的 Switch 与 Switch Lite 上完成，见适配说明第 5 节。

## 说明

本版不改变串流协议实现；上游 v0.1.6 的已知限制（无 H.265、无码率设置、音频无抖动缓冲等）继续存在。
