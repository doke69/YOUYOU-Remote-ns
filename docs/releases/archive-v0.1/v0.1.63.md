# v0.1.63：自定义高码率试用

沿用已验证的v62 UDP初始化与1MiB收发缓冲；不改变编码、分辨率、帧率、播放缓冲和垂直同步。

## 使用

菜单 → 显示 → 画质与帧率 → 画质档位 → 自定义，可选30、50、75、100 Mbps。先30，再50、75、100逐档检查。每档保持相同运动场景与其他设置，观察实际码率、缺包、重传、等待IDR、显示间隔和操作延迟。

自定义模式仅本次会话生效，不覆盖磁盘中的稳定画质配置。退出重开恢复原档位；也可以直接选回原画。配对与存档不变。设置应用可能按现有逻辑重连。

## 协议依据

原版TV和手机协议支持VideoQuality.Custom=6、max_custom_bitrate字段8。手机自定义数值流以每秒比特为单位：50 Mbps写入50,000,000，100 Mbps写入100,000,000。初始连接和在线CaptureSetting请求均携带该字段。自定义档位间变更同时更新CaptureSetting与既有码率反馈，不能只提高反馈上限。

本地原版分析证据索引：C:/uu/high-bitrate-probe/EVIDENCE.md。使用此前授权的离线APK读取方式；未启动原版程序或新增逆向服务。

## 限制

请求值不保证实际流量。原版编码器、自适应控制、画面复杂度、Wi-Fi及Switch接收能力都可能限制实际码率。必须看到真实流量再评价50/100 Mbps能力，不能将菜单数值当作已达到。保留帧大小和队列保护，不因本次试用扩大保护阈值。
