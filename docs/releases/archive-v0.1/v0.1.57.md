# v0.1.57：YOUYOU远程界面调整

更新日期：2026-10-23。此页记录本地测试候选；本次文档同步不代表 v57 源码或二进制已经发布到主分支。

## 使用上的变化

- 应用名称改为 **YOUYOU远程**，使用原创蓝色 Y 标识；首页、关于页和应用元数据统一显示版本号。
- 恢复此前清晰的图标资源，仅替换缺失或异常的触屏、鼠标等图标；原始品牌标识不用于新界面。
- 常驻网络信息采用贴右的紧凑四行布局，恢复半透明圆角底与轻微文字阴影；展示局域网/公网、显示帧率、码率、往返延迟、初传缺口、解码耗时和编码格式。
- 首页及登录页移除固定的通用 A/B/方向键教学；普通断开、刷新成功等状态不再重复按键提示。错误、加载和登录过期信息保留。
- 首页重点说明两个特殊操作：**长按 − 切换手柄/键鼠**；**＋ 在键鼠模式按一下打开菜单，在手柄模式长按打开菜单**。
- Windows 快捷操作中，显示桌面、任务管理器、切换窗口直接执行；锁定桌面、重启电脑和关机需要确认。

## 构建与资源处理

- 版本来自统一构建标签；应用名称采用明确的 UTF-8 编码写入 NACP 的标题字段，修正 Windows 构建中的中文名称乱码。
- 自有品牌、触屏和鼠标资源随源码构建；可选本地图标资源不等于公开仓库已经附带全部参考贴图。
- 保留原程序路径 `switch/UURemote-ns/UURemote-ns.nro`，不因显示名称变化迁移配对及设置。
