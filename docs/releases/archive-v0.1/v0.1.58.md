# v0.1.58 高码率实时诊断

> 状态：**诊断-only 审核候选**。源码已通过最终构建和静态检查；**未部署、未在 Switch 真机验证**。本版不修复高码率卡顿，只增加定位数据。

## 范围

- 保留 v0.1.57 的 YOUYOU 品牌、NACP 标题/图标、设置、配对、LAN、H.265、NV12 导入和菜单行为。
- 只增加 schema 12 实时诊断与 PC 接收脚本；**不修改**队列、码率、帧 pacing、接收 deadline，也不修改 NACK/RTX/协议行为。
- 目标用于高码率卡顿定位（首个现场为 Lite 设备），把网络初传/RTX、严格接收器包/组帧处理、AU 解码队列、显示渲染分开记录。

## 发送端（Switch）

- 每秒一组，拆为 `core/network/media/render` 四个独立 UDP JSON datagram；每组硬上限 1200 bytes。
- 四组共享 `schema=12,pair,session,seq,epoch,ticks_ms,parts=4`；单组超限只跳过该组并计数，不终止进程；其他组继续发送。
- 只使用 allowlist 数值/短字符串字段；不发送 Snapshot、媒体 payload、SDP、凭据或完整配置。
- 媒体新增：AU 大小/累计/2MB 拒绝、队列 frames/bytes 高水位、出队等待（dequeue−enqueue，非解码处理）、解码 max 与 >8/16/33ms 计数、最后解码年龄。
- 严格接收器新增：buffered bytes/高水位、input messages/batches/max batch、incoming/tick wall time 与 calls；计时包含当前锁/回调处理，不是 GPU/CPU compute。
- 渲染新增：work/present/loop/upload 的 avg/max、>25/50ms 循环、new-frame gap p95/max/overflow、GPU/映射和 UI/stats 标志；present 含 VSync，不能标成 GPU compute。
- 诊断计入新 generation 的 AU；旧代际回调不会污染新 epoch；2MB AU 拒绝保持不变。

## PC 接收端

- `scripts/telemetry_receiver.py`，Python 标准库。
- 仅私网/loopback 显式绑定；校验来源 IP、schema/字段 allowlist、固定 `version=0.1.58`、类型/有限值、pair 常量时间比较。
- 四组合并；不完整/过期记录为 `complete:false` 并列出 `missing_kinds`；不把缺失值填 0。
- 输出 `telemetry.jsonl`（20MB 滚动、最多3份）、`latest.json`、`health.json`（空闲也每秒更新）、partial 记录；pair 不进入任何输出。
- 接收序号缺口与视频初传缺口分开记录。
