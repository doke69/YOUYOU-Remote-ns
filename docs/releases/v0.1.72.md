# v0.1.72：队列唤醒成本优化候选

电脑侧离线候选，已构建和核对安装包；未部署、未真机验证。保留 v70/v71 原包，以及 v62 已验证基线。

## 依据与改动

接收队列此前每取出一个元素都通知等待空位的生产者。实际 Switch 构建的通知路径会进入 `svcSignalProcessWideKey`，即使没有线程需要唤醒。

本版在原队列 mutex 内跟踪等待者，仅在确有等待者时通知。保留满队列等待、停止时全部唤醒、原容量和数据处理次序。计数也涵盖已通知但尚未恢复的线程，避免多生产者场景漏唤醒；虚假唤醒继续检查原谓词。

这是减少不必要系统调用的局部优化，尚未确认其对 CPU3 或 50 Mbps 卡顿的实际影响。没有改变视频认证、解密、完整帧检查、补包参数、系统服务、频率或绑核。未新增或运行测试套件，后续仍需同条件真机验证。
