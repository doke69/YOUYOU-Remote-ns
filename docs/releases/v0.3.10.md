# 0.3.10 — 安全设置修正

日期：2026-10-25。仓库名YOUYOU-Remote-ns；程序内部目标名和SD配置目录保持UURemote-ns，避免登录/偏好迁移断裂。

- SimpleAction此前错误地走TEXT通道；现在改走CONTROL，并独立跟踪该通道开闭，剪贴板仍走TEXT。
- AutoLockScreen的字段5：开启2、关闭1。此前代码反向编码。APK分支和LinuxSET_AUTO_LOCK解析交叉印证。
- 原版手机开启静音先发MUTE_SYSTEM(14)，再发MUTE_TEMPORARY(18)或MUTE_PERMANENT(17)；关闭发MUTE_RESTORE(16)。此前遗漏14。
- 未保存设置的电脑默认静音/结束恢复为开、锁屏为关；保存过的明确值保留。控制通道就绪后每次连接应用完整有效策略，不能只应用有保存键的项目。
- 后台应用成功不额外弹横幅，失败仍提示；诊断只记固定命令编号和发送/排队/失败，不记载荷或设备标识。

来源：本地已授权参考APK的AutoLockScreen.h、B9/b0.v0/w0调用逻辑；Linux实现[src/system_actions.rs](https://github.com/VallierDev/uu-remote-linux/blob/main/src/system_actions.rs)和CONTROL通道处理。实现由本项目自行编码，没有复制认证常量。

验证：默认/保存选择/恢复单独保存、两步静音顺序、CONTROL常量、开启/关闭和静音Protobuf帧检查通过；Switch编译/链接/资源核对通过。已备份并安装测试机、回读一致。没有在开发电脑直接执行锁屏/重启/关机，也未宣称电脑端执行已经验证。用户实测待补。
