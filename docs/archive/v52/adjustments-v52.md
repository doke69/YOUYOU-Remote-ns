# v52 调整报告

## 传输与画质

先修复损坏参考帧／组帧，随后独立统计初传缺口、补包、已交付／丢弃帧、解码及实际提交。不会用单个解码FPS解释所有卡顿。局域网策略在候选连通与提名阶段做偏好；公网候选、可用中继作为回退保留。遥测分别显示地址族和真实端点匹配，不能凭 prflx 标签认定中继。

码率控制保留自适应；上限是约束，不保证静态场景持续达到。帧率／分辨率／编码调整涉及电脑捕获设置和接收器重建，在线操作仍可能重连，不再把成功状态码等同于实际编码行为。

## 解码与显示

NVDEC硬件帧的NV12面直接导入GPU，缓存底层分配／映射而非长期锁住池中AVFrame，减少CPU回传／RGBA上传。保留安全回退；限制尺寸、偶数采样与内存范围。GPU路径与新UI按层合成，菜单背景显式不透明。36/37的问题已记录，不能删掉历史失败后声称一直稳定。

## 界面与输入

主页聚焦设备连接；串流设置、Windows快捷操作、网络信息各有页面。多点触控独立于手柄／键鼠模式。输入模式切换前释放旧输入并等待按钮抬起。圆角纹理由覆盖率计算并缓存，稳定绘制复用纹理；首次生成仍有CPU成本。

公开源码不包含参考APK提取的贴图；缺少可选纹理时使用项目内原创几何回退，顶部保持文字“uu远程”。这与原52卡内参考素材外观有差别，当前不作为最终视觉验收结果。

## 本次审核修正

- 提供4个实际依赖源码覆盖及哈希，避免网络优化只存在本机ignored external目录。
- 提供四份GLSL源码和编译脚本；GPU库路径改为可配置并提供清晰缺失报错。
- 扩大Git排除规则；不提交签名材料、会话、配置、诊断和实验工具。
- 多点触控在一个快照里出现手指替换时，不复用刚消失触点的编号；视口无有效尺寸时取消触控。
- 发布资料统一标出未验证项目，不发布含本地签名材料的二进制。

这些修正只在审核分支，未覆盖正在使用的源码目录和SD主程序。后续需完整构建、触点快速替换／10指边界、多次登录重开、菜单输入隔离和网络回退专项验证。
