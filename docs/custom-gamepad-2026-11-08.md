# 本地操作、远程布局与自定义按键

候选 `0.3.75-r7map`，在 R6 双手柄基础上继续修改；仅本地诊断包，不自动部署或上传。用户已反馈 R6 双手柄使用基本正常，但横握 Joy-Con 和本地/远程按键含义混乱。该反馈不等于 R7 已真机验证。

## 交互规则

1. 本地菜单保持 Switch 逻辑：完整手柄 A 确认、B 返回，摇杆移动；横握单 Joy-Con 用右侧面键确认、下侧面键返回，摇杆移动。两名玩家均可操作菜单。菜单占用期间远端收到中立输入。
2. “远程游戏按键”明确控制远程输出，提供“Switch 按键习惯”和“Xbox 按键位置”。沿用既有 `xbox_layout` 存储及旧值，避免无意改变已保存布局。
3. 三种布局均先标准化为逻辑 A/B/X/Y，再经过同一远程转换。单 Joy-Con 取消固定按位置的特殊分支；横握后的右/下/上/左面键分别作为逻辑 A/B/X/Y。
4. 本地菜单提示和远程游戏按键设置分别展示；完整手柄、左横握、右横握均有四面键位置到当前 Xbox 输出的对照图。对照图使用与发送路径相同的 `padTarget` 计算，不维护另一套展示映射。

## 自定义

入口：“外设 → 手柄设备 → 远程游戏按键 → 自定义远程按键”。

- 完整手柄、左横握、右横握各存一份固定长度映射。同类型的两名玩家共享该类型映射，不新增按设备身份绑定。
- 按来源键选择电脑收到的 Xbox ABXY、方向键、LB/RB、LT/RT、L3/R3、Start/Back，或“不发送”。多个来源可以映射到同一目标；根据当帧所有来源合成输出。
- “跟随预设”让对应键跟随远程布局；“恢复当前手柄默认”清除当前类型的所有覆盖。
- 不存在的单 Joy-Con 来源键禁用。短按 +/- 的远程输出可改，长按本地菜单快捷键保持独立。
- 不增加摇杆轴改绑、键盘/鼠标按键改绑或宏。
- 数据在现有 UI 首选项边界检查为 3×16 整数，取值 -1..16；向内部传递类型化数组。改绑、恢复默认和更换预设均释放已有远端输入并等待实体键松开。

## 验证边界

离线手柄测试覆盖：左右 Joy-Con 横握坐标、两种统一预设、按钮改为扳机、禁用、重复目标合并、中立释放、Start/方向键输出、本地摇杆导航与远程隔离、双人独立长短按和时钟回绕。未运行整套 core/RTC 测试。

最终 NRO、版本、来源清单、10 个保护文件和 R5 构建选项核对结果见 `C:/uu/releases/diagnostics/custom-gamepad-20261108/REVIEW.md`。完整编译不等于实际页面渲染、SD 首选项写入恢复或真实游戏映射验收。

真机应分别检查三种组合（合并 Joy-Con、双横握 Joy-Con、合并 Joy-Con 加完整外接手柄）：本地确认/返回与导航、两种预设下四个面键、每种布局独立改绑和重启恢复、禁用与恢复默认、按住重复目标之一时释放另一来源、短按 Start 与长按本地菜单，以及打开菜单时游戏不响应本地操作。特别核对两名玩家使用相同类型时的共享映射是否符合预期。

旧 R6 NRO 保留。回退后 R6 忽略新增 `gamepad_bindings` 字段；若在旧版重新保存首选项，旧版可能丢弃该新增字段，应保留测试前首选项备份。
