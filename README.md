# YOUYOU远程 · Nintendo Switch

在 Switch / Switch Lite 上远程使用自己的 Windows 电脑，通过手柄、键鼠映射或触屏操作桌面和游戏。

这是基于 [Antman2023/UURemote-ns](https://github.com/Antman2023/UURemote-ns) 的非官方适配分支。项目使用 UU 远程账号和电脑端服务，但**与网易、任天堂无隶属或背书关系，不是官方客户端**。请仅连接你有权控制的设备。

## 已有功能

- 扫码/短信登录、本地会话恢复、手动刷新设备；按服务返回状态区分在线和离线。
- 首页记住上次成功连接的电脑，按设备 ID 恢复，不受设备列表排序影响。
- H.264 / H.265、NVDEC 硬件解码、Deko3D NV12 显示路径。
- 720p / 60 FPS、播放缓冲、垂直同步、声音与画质设置。
- 省流 **5 Mbps**、清晰 **12 Mbps**、高清 **20 Mbps**、原画 **30 Mbps**；这是请求档位，不保证实际持续吞吐。
- 两套键鼠方案、实验性 Xbox 手柄直连、手机鼠标指针与平板多点触控两种触屏方式。
- Windows 快捷操作、部分安全设置、剪贴板确认后粘贴文字。
- 左下角半透明常驻网络数据、详细网络与运行诊断。
- 项目图标与 Noto Sans SC 开源字体；字库一次加载到内存，避免绘字时反复读 SD 卡。

原生 IPv6、TURN TCP/TLS 的正式互通、所有设置在线无重连、完整自动解锁等尚未完成或未充分验证。硬解耗时包含处理/等待，不是纯硬件执行时间。不同场景、频率和网络下不能保证相同延迟。详见[状态表](docs/project-status.md)。

## 快速使用

1. 在有权访问的电脑上登录官方 UU远程，保持在线。
2. 在 Switch 以完整应用模式通过 sphaira / hbmenu 打开自编译的 NRO；避免相册小程序模式。
3. 手机官方 App 扫码确认。设备类型可能显示 TV，设备名为 Switch 主控端：当前实现沿用上游 Android TV 注册接口，并非官方 Switch 支持。
4. 刷新并选择在线电脑，进入桌面。首页 **长按 ＋** 退出应用。
5. 串流时 **长按 −** 切换键鼠/手柄；键鼠模式 **按一下 ＋** 打开菜单，手柄模式 **长按 ＋** 打开菜单。

新配置为 720p60、H.265、高清20 Mbps、垂直同步开启、播放缓冲8 ms、键鼠方案一。已有配置按版本迁移，详见手册。程序不会自动超频。
